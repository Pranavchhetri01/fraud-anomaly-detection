# Fraud and Anomaly Detection System

An end-to-end data science project that develops and compares supervised fraud-detection models and unsupervised anomaly-detection models.

The system will assign fraud-risk scores to financial transactions and flag suspicious activity for investigation while minimising unnecessary alerts for legitimate customers.

## Project Objectives

- Understand patterns associated with fraudulent transactions.
- Prepare highly imbalanced financial transaction data.
- Develop supervised fraud-detection models.
- Develop unsupervised anomaly-detection models.
- Compare models using appropriate evaluation metrics.
- Explain individual predictions and overall model behaviour.
- Build an interactive fraud-monitoring application.
- Evaluate the business impact of false positives and false negatives.
